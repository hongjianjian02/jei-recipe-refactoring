# JEI Recipe Refactoring · 附魔与修复查询

面向 **Minecraft 1.21.1 NeoForge** 的客户端查询增强模组，将装备、附魔书和修复材料的关系整理成 **6×4 滚动网格**，支持 JEI 和原生 EMI。

当前版本：`1.2.5-mc1.21.1`。模组 ID：`anvil_enchant_guide`。

## 主要作用

| 查询入口 | 展示内容 | 默认操作 |
| --- | --- | --- |
| 装备、工具 | 可用附魔书及修复材料 | 指向物品按 `R` 或 `U` |
| 附魔书 | 可以接受该书附魔的物品 | 指向附魔书按 `R` 或 `U` |
| 修复材料 | 可以用该材料修补的装备；相同目标的材料合并展示 | 指向材料按 `U` |

按键遵循所用配方浏览器的设置，上表为默认键位。EMI 还支持从不可附魔但可修复的装备（如狼铠）进入修复材料信息页。

- 支持滚动浏览、最高等级与全部等级切换，附魔等级以罗马数字显示在附魔书图标上方。
- 按装备类别组织物品，单独展示诅咒，提供附魔冲突和基础经验费用提示。
- 保留多附魔书、实际出现的高等级书，以及物品名称、损伤和数据组件的差异。
- 从当前世界或服务器同步的附魔注册表、标签、组件和物品适用钩子建立索引，支持模组与数据包附魔。
- 在进退服、换服和数据重载后刷新数据；旧查询失效时提示重新查询。

本模组提供信息查询，不新增附魔、物品或机器，也不改变实际铁砧、仪式和机器的处理结果。

## 运行环境与前置

| 项目 | 版本与要求 |
| --- | --- |
| Minecraft Java Edition | **1.21.1**，必需 |
| NeoForge | 构建基线 **21.1.265**；依赖声明要求 `21.1.265` 或更高版本，仍须用于 Minecraft 1.21.1 |
| Java | **21** |
| JEI | 可选客户端依赖，推荐 **19.76.1.481**；声明范围为 `19.76.1.481 ≤ 版本 < 20` |
| EMI | 可选客户端依赖；原生查询功能仅启用 **1.1.24+1.21.1+neoforge** |

版本依据见 [构建配置](build.gradle) 和 [模组依赖声明](src/main/resources/META-INF/neoforge.mods.toml)。EMI 的元数据范围为 `1.1.24` 或更高，但原生查询涉及版本相关接口，代码另有上述精确版本检查。

**显示查询页面需要至少安装 JEI 或 EMI 中的一个。** 两者都未安装时，本模组可以加载，但没有查询界面。只需在客户端安装，服务器无需安装本模组；成品 jar 不捆绑 JEI、EMI 或其他联动模组。

### JEI 与 EMI 如何选择

- **仅安装 JEI：** 使用 JEI 的基础查询页面。
- **仅安装受支持的 EMI：** 使用原生 EMI 的基础查询页面，不需要 JEI。
- **同时安装：** 两个插件分别注册；EMI 原生查询启用后，移除转入 EMI 的本模组基础重复页，JEI 插件仍然可用。
- **其他 EMI 版本：** 原生查询插件不启用；若同时安装受支持的 JEI，仍可使用 JEI。其他版本的 EMI 桥接效果尚未验证。

Iron’s Spells 和 TaCZ 的专用扩展目前由 JEI 提供，不能仅靠 EMI 启用这些专用页面。

## 安装与使用

1. 使用 Minecraft 1.21.1、NeoForge 和 Java 21 创建客户端实例。
2. 安装符合上表要求的 JEI 或 EMI。
3. 将本模组 jar 放入实例的 `minecraft/mods` 目录，重新启动游戏。
4. 进入世界后，从物品或附魔书执行查询，在页面中切换等级、滚动网格并查看提示。

在受支持的 EMI 中，材料修复网格成功注册后，本模组在“铁砧修复”分类展示材料网格，隐藏准确识别的 EMI 原生材料修补、两件装备合并和附魔书附魔旧页。网格注册失败时保留原生页面。其他模组添加到该分类的页面，以及机器、升级和工作台配方继续保留。

## 查询范围与提示含义

- **铁砧与附魔台条件不同：** 页面按普通铁砧附魔书适用规则查询，不把附魔台的可用范围直接当作铁砧范围。
- **多附魔书：** 某件装备可能只接受书中的部分附魔，具体结果仍由游戏和相关模组决定。
- **高等级书：** 显示定义内等级和实际观察到的额外等级，不无限生成超等级序列；显示高等级书不意味着普通铁砧可以突破等级上限。
- **费用：** 提示的是基础附魔费用，不等于包含已有附魔合并、修补代价、改名和模组修改后的最终铁砧总费用。

## 从源码构建

准备 Java 21，使用仓库内的 Gradle Wrapper。构建配置使用 ModDevGradle `2.0.148`。

Windows PowerShell：

```powershell
.\gradlew.bat build
```

Linux / macOS：

```bash
bash ./gradlew build
```

构建产物：

```text
build/libs/jei_recipe_refactoring-1.2.5-mc1.21.1.jar
```

`-PwithoutJei` 和 `-PwithoutEmi` 分别关闭开发客户端的对应运行依赖，不移除编译接口或改变发布 jar 的可选支持。
